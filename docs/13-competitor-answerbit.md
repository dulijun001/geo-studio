## 结论

1. **功能差距比预想小。** 真正的缺口只有两条，其中一条建议不补。
2. **唯一该补的：多引擎常态化。** 元宝/DeepSeek adapter 已写在 `apps/worker/src/trackers/`，卡在 selector 未对真 DOM 验证；夸克/Kimi 仍是 stub。腾讯四引擎（豆包/元宝/DeepSeek/Kimi）已成行业标配。
3. **建议不补：天级全量刷新。** 腾讯有内部 UI 自动化农场；我方受 D43 护栏（50 题上限 / 间隔 300-900s / 50 题跑 7h）。物理上限，硬追会重演 2026-06-08 的 458 题 fan-out 风控事故。
