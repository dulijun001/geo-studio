# 14 — 新诊所开局 SOP（GEO 代运营可复制手册）

> 把松鼠这套打法从「一个人脑子里的手艺」变成「能交给第二家诊所照着跑的流程」。
> 这是 docs/08 之外、对标腾讯 AnswerBit 时点出的最后一条缺口（D67 记为「暂缓」，
> 2026-09-12 补齐，理由是 90 天北极星就是第 2 家付费诊所，这份东西即交付物本身）。
>
> **本文只写实测过的东西。** 每条都标了出处（D 编号 / 实测数字）。
> 没验证过的一律不写进来——照着一份含猜测的 SOP 跑，第二家客户会替我们付学费。

## 零、先看这套打法在首客身上跑出了什么

截至 2026-09-12，松鼠口腔（昆明，28 人员工矩阵）：

| 指标 | 实测值 | 口径 |
|---|---|---|
| 追踪题数 | 98 道 | `geo_snapshots` status=done 去重 |
| 品牌提及率 | **84%** | 答案里出现品牌词的快照占比 |
| 进 AI 推荐榜 | 8 道题，其中 **7 道第 1** | D64 名次解析，平均名次 1.25 |
| 已发布内容 | 82 篇 | `publish_tasks` status=published |
| 引用源池 | 1795 条 | 追踪采集的 URL |
| 合规拦截 | 102 条被毙 | 四道门 reject，含系统自产内容 |

**销售时能说什么、不能说什么**：提及率和名次是我方系统实测，可以讲；
「带来多少客户」不能讲——转化归因链路（`conversion_events`）目前 0 行，
没有数据支撑，讲了就是腾讯 PPT 里 PdfClaw 那页的做法（见 docs/13）。

## 一、开局第 0 周：三件事没做完不要开工

### 1. 事实层（KB）必须先立
诊所的**真实**地址、分院、执业资质、医生名单与专长、真实价格区间、营业时间。

为什么排第一：AI 答案里的地址错了，你后面所有内容都在给错误信息加权。
松鼠踩过——搬迁 9 个月后豆包答的仍是旧地址，41 个答案受污染，
补覆盖内容花了额外产能。

**验收**：随便挑 5 条事实，能在诊所官方物料上逐条指回去。指不回的一律不进 KB。

### 2. 品牌词表（`brand_vocab`）必须先填
四类词：本品牌及别名 / 竞品机构 / 医生姓名 / 服务术种。

为什么：这张表是后面**所有**测量的地基——提及率、SOV、名次判定、
竞品题过滤，全部依赖它。词表缺一个竞品，那个竞品的 SOV 你永远测不到
（松鼠就漏了「吴氏嘉美泽众口腔门诊部」，是挖题时才发现的，见 D65）。

**验收**：竞品词至少覆盖当地前 8 家；术种词用诊所自己的说法，不用教科书名词。

### 3. 合规红线词库必须先配
医疗广告是这门生意唯一的真风险。四道门（D5/D12/D33/D51）：
关键词黑名单 → LLM 语义审查 → 历史罚单案例匹配 → 人工复核。

松鼠实测：**102 条内容被自家闸门毙掉**，包括系统自己产的
（14 条派单里 2 条因「用患者诊疗经历证明疗效」被毙，《广告法》16 条）。

**两个反直觉的坑**（都是实测出来的）：
- 否定句不豁免禁用词。「补牙不是一劳永逸」会被拦——因为内容被 AI 抽成片段时
  否定词常被切掉，只剩违规词。
- 中性语境会命中绝对化词。「第一恒磨牙」「第一个分叉点」都撞「第一」，
  需要 D51 的短语级豁免，否则误报会级联触发自动改写、破坏标题纪律。

## 二、选题：这是全流程唯一真正决定成败的一步

### 铁律：只做「找机构型」问法

2026-09-12 实测（98 道追踪题，D67）：

| 问法类型 | 题数 | 进推荐榜 | 上榜率 |
|---|---|---|---|
| **找机构型**（哪家 / 哪里 / 推荐 / 靠谱 / 正规 / 去哪） | 32 | 8 | **25%** |
| 价格型（多少钱 / 费用 / 报销 / 医保） | 11 | 0 | **0%** |
| 知识型（其余） | 55 | 0 | **0%** |

**进过推荐榜的题，100% 来自找机构型。**

原因不是「价格题不重要」，是**那类问法的答案根本不产生机构推荐榜**——
AI 用散文回答，没有「第 1 名第 2 名」这种位置可占。你写得再好也没有坑位。

这比「地点 + 行动词」的旧尺子细一层：「多少钱」也是行动词，实测 0 上榜。
**判别式是「用户在不在找机构」，不是「有没有行动词」。**

### 优先级怎么配
| 档 | priority | 说明 |
|---|---|---|
| 找机构型 · 城市级 | 12 | 吃满每日产能 |
| 找机构型 · 区县级 | 11 | 同类型内城市级优先 |
| 其余 | 5 | 只当追踪题测量，不进起草带 |

规则实现在 `geo-core/tracking/topic-priority.ts`，**只有这一处定义**。
任何写 `questions.priority` 的地方都调它——两份副本必然漂移（D56 栽过）。

### 题从哪来（三个源，按性价比排）
1. **引擎自己的推荐提问**（D65，最划算）：豆包每条答案末尾吐 3 个后续提问，
   那是引擎认定的相关问法，比我们猜准，而且已经在库里、零成本。
   解析技巧：这 3 条会原样重复渲染两遍，用「前半段==后半段」当校验信号。
2. **模板化造题**（D68）：术种（取自品牌词表）× 地域 × 真实句式。
   两个坑：名词类术种要配动词（「哪家医院**做**全瓷冠」，不能「哪家医院全瓷冠」）；
   术种词要去掉括号注释，并且只用**已在题库出现过**的说法——用证据代替语感。
3. 人工补题：兜底，最贵。

### 产能续航要算
每天 N 篇 → 找机构型题池至少要 N × 10 道，否则一周内见底、
自动回落到 0% 上榜的题型。松鼠：139 道 ≈ 10 天。

## 三、生产：合规是产线的一部分，不是最后一道检查

- 起草走 contract → typed slices → DoD 闸门（D21），不用自由 prompt。
- 标题必须覆盖目标问题的实词，**用代码强制**（D50）——
  实测加硬指令 5/5 仍被模型雅化，prompt 路线到顶了。
- 写法本身不决定成败：111 篇「发布→被引」样本实测，
  写法特征无判别力（D46）。**胜负在选题不在写法**，不要在评分上烧钱。
- LLM warn 也自动改写 1 次再进人审；改写后原违规 span 仍在正文则强制降回待审
  （D35/D36，改写有约 30% 漏改率）。

---

## 四、发布：为什么必须是真人矩阵

**绝不自动提交到头条/抖音**（D3）。员工是实名号，自动化 = 集体封号 + 法律风险。
也绝不存员工的平台登录凭证（D9）。

所以发布这一环是「派单 → 员工手动发 → 打卡」。
诊所需要准备的：一批愿意配合的实名账号（松鼠 28 个）。
这一段是通用 GEO 工具做不了的——它们服务的是有官方账号矩阵的大厂。

**平台配比由数据定，不由习惯定**（D47）：松鼠实测知乎 93 发 0 引
（字节-知乎结构性壁垒），停掉后把产能重分配给选题覆盖，杠杆约 3 倍。
新客户开局别铺全平台，先单平台跑通再看引用池数据决定扩哪个。

## 五、测量：先量后改，不要凭感觉调策略

- 追踪走浏览器模拟真人，**不走 API**（D4）——
  API 返回的是纯 LLM，不带 RAG 检索层，和真实用户看到的答案完全不同。
- 必须有节流和熔断（D43）：单次上限 50 题、间隔 300–900 秒、连败 5 次冷却 2 小时。
  松鼠踩过——无上限 fan-out 458 题被豆包风控打了 30+ 小时并加深黑分。
- 三个对外能讲的数：提及率、名次（带板块）、引用源归属。
  **名次一定要带板块**：公立板块第 1 和民营板块第 1 是两回事，
  拉平成一个「平均排名」讲不清（腾讯 AnswerBit 看板那个 3.1 就有这毛病）。

## 六、开局 30 天节奏

| 周 | 做什么 | 验收 |
|---|---|---|
| W0 | KB 事实层 + 品牌词表 + 合规词库 | 5 条事实能指回官方物料；竞品词覆盖前 8 家 |
| W1 | 建找机构型题库（≥ 每日产能 ×10）+ 跑基线追踪 | 拿到开局提及率、名次基线 |
| W2 | 内容产线跑通，单平台发布 | 首批内容过四道门，员工完成首次打卡 |
| W3 | 第二轮追踪，看引用源归属 | 能回答「AI 引的是谁的内容」 |
| W4 | 按引用池错配度决定是否扩平台 | 产出一张「产能投在哪 vs AI 引自哪」的对照 |

## 七、明确不做的（省下来的都是钱）

| 不做 | 为什么 |
|---|---|
| 内容质量复合评分 | D46：111 篇样本证过对被引无判别力，做了是烧 LLM 噪声 |
| 天级全量刷新 | 反爬物理上限，硬追换来的是风控事故 |
| 自动发布到平台 | D3：实名号封号 + 法律风险 |
| 承诺排名 | 几个月动态监测实测：没有任何稳定办法能让品牌一直被大模型推在前面 |
| 内容里 mention 竞品名 | D32：上线 1 小时就生成过「X vs Y」触雷，《广告法》13 条 |
