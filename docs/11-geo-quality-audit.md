## 1. 第一性原理:被 AI 引擎引用的因果链

```
Stage 0  测量         → 你能不能看见结果      【残废:豆包 24% 成功率,DeepSeek 全盲】
Stage 1  进入候选池   → 内容在不在引擎检索范围 【偏科:只覆盖自媒体平台;垂直站/POI/百科零覆盖;发布漏斗堵死】
Stage 2  池内排序     → 凭什么选你            【漂移:标题匹配无硬闸门;时效冻结;权威度空白】
Stage 3  抽取引用     → 选中后能不能被干净引用 【强项:直答/自立块/实体显式,真机验证有效】
```

**当前投入产出倒挂:资源集中在 Stage 3(已经最强),而 Stage 0/1/2(决定生死)最弱。**

## 3. 代码面审计结论(详见产线审计,2026-07-03)

### 3.1 真本事(有实证背书,保留并加倍)
1. 标题=子问题原句指令 + D31/D44 子问题矩阵(对齐唯一显著因子)
2. 机构硬事实真值块注入(`ai-draft-core.ts:603-608`)——豆包真机实测直接抄这些字段
3. 120 字直答 + 35-90 字自立引用块 + 禁模糊指代(对应 RAG chunk 抽取物理机制)
4. FAQ 答案嵌「区县+品牌+建议」长尾句
5. 引用白名单 + D34 ground-truth 校验(防降权)

### 3.2 形式主义(降级或砍)
1. **L1 九法评分器**:权重锚 Aggarwal 2023 英文论文;自家实证已推翻该坐标系;`pickTopicKeyword` 从标题自身提词再数正文密度=循环自证;quotation 计任意「」引号=噪声;statistics 奖数字密度与零幻觉红线结构性对冲(D33/D34 翻车的张力来源)。由它驱动的 auto-rewrite 在烧 LLM 成本优化 regex 满足度。
2. **Layer A 全套**(llms.txt/JSON-LD):无国内引擎消费证据、英文小节标签服务中文引擎、域名被 ICP 拦、D43 实测引用源零命中。且 llms.txt 里 `Experience: X years` 与 D33 正文禁令自相矛盾(合规风险)。
3. Trust Block 占 L2 权重 30(最高)——对豆包排序影响未验证,权重超过证据。
4. `tactics_applied` 自报字段、cliché 检查——装饰性。

### 3.3 缺失能力(按杠杆排序)
1. **标题匹配硬闸门**:DoD 加纯字符串检查(标题必须含 primary_query 全部实词),毫秒级,几行代码,保护全战略地基。
2. **测量层重建**:追踪成功率修复 + DeepSeek 首跑(先实证采数据,再定 DeepSeek 策略——无研究材料,不允许拍脑袋)。
3. **权重再校准回路**:D43 起已有发布→引用 URL 级闭环数据(14 正样本/95 负样本),用自家数据回归真实系数替换论文值。commit 6476daf 已解耦 scorer 与 prompt,前置就绪。
4. **时效信号刷新**:已发布内容零更新机制;D37 B4 列了战术但代码层为零。
5. **实体权威度层**:进入 yslw/mebkq/政府定点名单/抖音 POI/百科的能力为零——D44 承认这是城市级大词输掉的根因("输给公立三甲/连锁的实体权重")。
6. **平台引用反馈 → dispatcher**:哪个平台被引已采集,但不回流平台配比(docs/08 断点之一)。

## 4.6 P1-1 评分器再校准执行结果(2026-07-03)
