## 0. 前置认知(必读 10 分钟)

### 你在干什么

### 豆包怎么找到你?
豆包 RAG 只抓 3 类源:
1. **字节亲儿子生态**:头条号 / 抖音 / 头条百科 / 字节百科 — **优先级最高**
2. **公开 web + 权威平台**:知乎专栏 / 百度百科 / 搜狐号 / 行业垂直媒体
3. **结构化数据**:Schema.org JSON-LD(你的官网 + GEO Studio 输出 llms.txt 已经做了)

**反例**(豆包几乎抓不到):
- 微信公众号(反爬严)
- 朋友圈 / 私域社群
- 小红书(字节竞品)
- 邮件 / PDF 内部文档

- **百科 / 权威背书 1/10**:零基础 — **本月最大 ROI 在这**

## 1. Week 1(2026-05-22 → 05-28)— 基础设施 + 百科申建

百科一旦立起来,豆包答案直接拿你的词条做权威源,生效极快。医疗机构有营业执照 + 卫健委文号 + 医保定点,过审率 90%+。

**3 个百科都要建**:

| 百科 | 入口 | 申建材料 | 预计审核期 |
|---|---|---|---|
| **头条百科**(字节亲儿子)| baike.toutiao.com | 营业执照扫描 + 卫健委许可证 + 医保定点证 + 官方介绍稿 800 字 + 5 张外景/内饰图 + 3 个外部链接(头条文章引用) | 3-7 天 |
| **字节百科**(豆包亲儿子)| 通过头条百科同步进 | 同上 | 5-10 天 |
| **百度百科**(企业词条)| baike.baidu.com/error?type=create&title=昆明松鼠口腔 | 营业执照 + 工商信息 + 5 篇独立第三方媒体报道做参考资料 | 7-14 天 |

**词条标准结构**(全部按这个写):
```
昆明松鼠口腔
├─ 概述(200字):机构性质 + 地址 + 创立时间 + 资质 + 主营业务
├─ 历史沿革:成立时间 + 重要里程碑
├─ 资质荣誉:卫健委文号 + 医保定点 + 二级专科认定 + 所获奖项

├─ 服务范围:西山区 / 昆明
├─ 联系方式:电话 0871-68152121 + 地址 + 工作时间
```

## 2. Week 2(2026-05-29 → 06-04)— 矩阵铺量 + 医生认证

### 2.1 头条 + 抖音持续输出(常态化)

- 头条:13 号 × 2 篇/天 = 26 篇/天,持续 4 周
- 抖音:13 号 × 1 视频或图文/天 = 13 条/天
- 内容选题用 GEO Studio 「P0 失守题」面板 + KB 自动派生(V1.12 预期推出)

**抖音内容策略**(因为视频跟图文逻辑不同):
- 60% 知识科普(种植牙 5 年存活率 / 儿童涂氟 / 等)— 跟头条文章同主题不同形式
- 30% 病例展示(术前术后对比 + 医生讲解,**患者签字授权后**)
- 10% 机构日常(医生培训 / 设备介绍 / 患者口碑)

**陷阱**:抖音脚本生成 ≠ 真拍视频。要安排医生 / 助理实拍。每周固定 2 个下午拍 5-8 条视频备料。

### 2.2 丁香医生 / 好大夫医生认证(医疗 GEO 关键)

12 个主力医生(`brand_vocab.doctor` 表已有名单)全部认证:

| 平台 | 关键动作 | 工时/医生 |
|---|---|---|
| **丁香医生** | 注册 + 上传医师执业证 + 写专业简介 200 字 + 至少 3 篇科普回答 | 2-3h |
| **好大夫在线** | 同上 + 设置在线问诊价格(免费或低价初诊吸量) | 2-3h |

豆包 / 元宝在被问"昆明哪个医生靠谱"类题时,丁香 / 好大夫的医生页面是 RAG 高权重源。

**Deliverable**:Week 2 结束 12 个医生在两个平台都过审 + 至少 5 篇科普回答 / 平台

### 2.3 同行高赞回答补充(知乎攻势)

定位策略 — **不写新题,在已经热门的题下面补充**:
1. 知乎搜「昆明正畸医院推荐」「昆明种植牙集采」「昆明儿童口腔哪家好」(对应 GEO Studio 5 道 P0 失守题)
2. 找现有高赞回答(500 赞以上)
3. 写一个 800-1500 字回答,客观介绍多家,**自然带出松鼠口腔**(不要硬广)
4. 用机构号或团队医生认证号回答(权重高)

**5 道 P0 题各做 1 条,本周末完成**。

### 2.4 官网内容沉淀(给 Schema.org 喂料)

GEO Studio 已经生成的高质量内容,**同步发一份到松鼠官网** `https://www.ynsskq.cn`:
- `/articles/` 路径下每天一篇
- 每篇带:作者(医生) / 发布时间 / 主题分类 / FAQ 折叠区
- Schema.org Article + Q&A JSON-LD(GEO Studio Layer A 自动生成,要让客户网站直接拉)

字节 spider 抓官网时,这些内容会被识别为权威源。

## 5. 内容标准 / 合规红线(每篇必过)

**GEO Studio 已经在生产链路把这些做了**,但发到外部平台前**运营再扫一眼**:

| 红线 | 例 | 不能写 |
|---|---|---|
| 绝对化用语 | "最专业""第一""唯一""国内顶尖" | 任何级别词 |
| 疗效承诺 | "百分百""治愈""根治""无痛" | 数字疗效承诺 |

| 医生资质夸大 | 自称"专家""权威"前要看资质 | 高级职称要核实 |

任何一条踩了就医疗广告法,十万起罚。
