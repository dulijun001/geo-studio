# 03 - 医疗合规方案

## 为什么这一章是最重要的

**医疗广告违规的罚款起步 10 万,吊销医疗机构执业许可证是上限**。央视 2026 年初已经曝光 GEO 行业乱象,监管目光正在聚焦这个领域。我们是 SaaS 方,客户违规我们不承担主责,但:
1. 产品里如果**主动生成违规内容**让客户发,我们连带责任
2. 客户出事,我们的案例背书崩塌,卖不动后续客户
3. 口碑一次性塌陷,行业内传得飞快

所以合规审查**不是可选功能,是产品底座**。

## 法规依据(主要)

- 《医疗广告管理办法》(2006 修订,仍在用)
- 《广告法》2015 + 2018 修正(第 16、17 条直接约束医疗广告)
- 《互联网广告管理办法》(2023.05 实施)
- 《医疗机构管理条例实施细则》
- 最高法"关于审理食品药品纠纷案件适用法律若干问题的规定"
- 各地卫健委 / 市场监管局的补充文件

## 医疗广告违法红线(分级)

### 🔴 Level A - 零容忍(直接拒绝发布)

| 类型 | 例子 | 出处 |
|---|---|---|
| 保证性承诺 | "保证治愈""百分百见效""包治""绝对安全" | 广告法 §17(1) |
| 疗效断言 | "根治牙周病""永不复发""立竿见影" | 医广办 §7(1) |
| 患者案例前后对比 | "张女士治疗前后对比图""真实病例分享" | 医广办 §7(3) |
| 与其他医疗机构比较 | "比 XX 医院技术强""行业第一""全市最好" | 广告法 §16(3) |
| 医生/专家形象代言 | "北京协和 XX 教授强力推荐""国医大师钦点" | 广告法 §38 |
| 利用患者感谢信 | "感谢 XX 医生救了我的牙齿" | 医广办 §7(3) |
| 违法药品/器械推广 | 未经审批的药械名称 | 药品广告审查办法 |
| 医疗广告审批外内容 | 超出《医疗广告审查证明》范围 | 医广办 §3 |

### 🟡 Level B - 中风险(需改写或人工审批)

| 类型 | 例子 | 处理 |
|---|---|---|
| 绝对化用语 | "最好""首家""独家""领先""首选" | 改写成"专业""丰富经验" |
| 销售导向 | "买一送一""限时优惠""首诊立减 500" | 改成科普导向 |
| 弱保证表达 | "效果显著""放心选择""值得信赖" | 改成"临床研究显示..." |
| 有奖感言 | "在线咨询即送礼品" | 删除 |
| 诱导开方 | "长期服用 XX 有助于..." | 改成"XX 的作用机制..." |

### 🟢 Level C - 低风险(可自动放行)

| 类型 | 处理 |
|---|---|
| 科普知识(不含承诺、不含品牌比较) | 自动放行 |
| 医生简介(仅含注册信息、擅长领域)| 自动放行 |
| 就医流程介绍 | 自动放行 |

## 第一道:关键词黑名单

### 词库结构
```typescript
type ComplianceKeyword = {
  term: string           // 词本身
  level: 'A' | 'B'       // 风险等级
  category: string       // 'guarantee' / 'absolute' / 'comparison' / 'testimonial' / ...
  variants: string[]     // 常见变体(繁体、错别字、空格分隔)
  context_exempt?: string[]  // 上下文豁免(如"百分百"出现在"含糖量百分百"可豁免)
}
```

### 初始 A 级词(示例,实际部署前交法务评审)
```
保证, 包治, 根治, 治愈, 痊愈, 绝对, 百分百, 100%,
无效退款, 永不复发, 立竿见影, 立刻见效, 一次搞定,
最好, 最权威, 最先进, 第一, 首家, 独家,
北京协和, 上海九院, 华西口腔   // 明显医院名
治疗前后, 术前术后对比,
```

(完整表在种子脚本 `seed/compliance-keywords.csv`)

### 匹配策略
- 全文扫描(不分词,避免切词歧义)
- 繁简转换后再扫一遍
- 空格/标点忽略匹配(对抗"保 证")
- 命中一个词即视为命中该等级

## 第二道:LLM 语义审查

### Prompt 模板(关键)

```
你是一名熟读《广告法》《医疗广告管理办法》《互联网广告管理办法》的合规审查员。

【审查对象】
平台:{platform}
标题:{title}
正文:{body}

【审查规则】
1. 保证性承诺(保证疗效、包治、根治、100%等)——直接判高风险
2. 绝对化用语(最好/第一/首家/最权威)——判中风险
3. 患者案例、前后对比、感谢信——高风险
4. 医生代言、专家推荐、与其他医院比较——高风险
5. 诱导就医/诱导开方——中风险
6. 销售话术(优惠、买赠、限时)——中风险
7. 科普性内容、医生简介、就诊流程——低风险

【输出格式】必须是合法 JSON,不要有多余文字】
{
  "risk_level": "high" | "medium" | "low",
  "findings": [
    {
      "span": "命中的原文片段",
      "rule": "违反的具体条款",
      "suggestion": "改写建议"
    }
  ],
  "rewritten_body": "如果是中风险,给出完整合规改写版"
}

【审查对象】上文已给出。现在输出 JSON。
```

### 调用配置
- 模型:`doubao-seed-1-6-pro-250815`(或当时最新 Pro 版)
- temperature: 0(审查要确定性)
- max_tokens: 2000
- 重试:失败 3 次→降级到纯关键词结果 + 强制进人工审核
- 结果缓存:24 小时(相同内容不重复调用)

### 为什么用豆包不用 OpenAI
1. 中文医疗术语豆包 > GPT-4(本地化优势)
2. 便宜 10 倍
3. 数据合规(医疗内容留在境内)

## 第三道:人工审批台

### 界面要素(给管理员)
- 左栏:原始内容(标题+正文)
- 右栏:
  - 关键词命中高亮(红/黄色块)
  - LLM 分析结果(风险等级 + 具体违规点)
  - LLM 给出的改写版(可一键采用)
- 底部 3 个按钮:
  - **批准发布**(记录审批人 + 原因)
  - **手改后批准**(允许现场编辑后批准)
  - **拒绝**(必须填拒绝原因,发回运营)

### SLA
- 提交到有管理员看到:< 10 分钟(推送通知)
- 有管理员看到到决定:< 4 小时(员工发布窗口)
- 超时未审批:自动降级为拒绝,发回运营

## 审计日志要求

以下动作**必须**入 `audit_logs`:

| action | 何时触发 | 关键字段 |
|---|---|---|
| `compliance.keyword_hit` | 第一道命中 | level, hit_terms |
| `compliance.llm_review` | 第二道完成 | risk_level, llm_raw_response |
| `compliance.manual_approve` | 管理员批准 | reviewer_id, rationale |
| `compliance.manual_reject` | 管理员拒绝 | reviewer_id, reason |
| `compliance.auto_approve` | 系统自动放行 | stage_path |
| `content.publish_dispatched` | 派给员工 | staff_account_id |
| `content.published_url_recorded` | 员工回填链接 | url |
| `content.post_hoc_takedown` | 事后删除 | reason |

保留期:**≥ 3 年**(诉讼时效)。

## 事后风控(Post-hoc)

三道门不是万无一失的最后一道防线。配套机制:

### 1. 发布后扫描(每日)
- 对过去 24 小时内所有 `published` 状态任务,重新跑 LLM 审查(规则可能迭代、LLM 能力在进化)
- 发现新风险 → 通知管理员考虑"撤稿请求"

### 2. 撤稿流程
- 管理员一键标记 "请员工撤稿"
- 员工端收到推送 + 系统记录撤稿发送时间
- 员工撤稿后打卡(同样的回执机制)
- audit_log 记录全过程

### 3. 监管应对预案
- 客户收到市场监管局询问时,一键导出 audit_log 区间
- 我们作为技术服务商,能证明"已尽最大合规审查义务"

## 客户侧配置(每个租户可覆盖)

租户管理员可以:
- 新增本租户专属关键词(不能删除全局词)
- 调整 B 级词的处理策略(走 LLM 还是直接走人工)
- 指定额外审批人(法务顾问账号)
- 调整 SLA 时长

## 不做(明确)

- **不做"帮客户规避合规"**——产品不提供"如何绕过审查"的任何帮助
- **不做为"4800 元买推荐"客户服务**——开户要求客户签合规承诺书
- **不做事前法律意见**——我们是技术工具,不是法务顾问,文案里明确"本平台仅提供自动化辅助,合规责任由客户承担"
